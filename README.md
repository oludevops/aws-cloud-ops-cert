# AWS Cloud Operations Certification Labs

Hands-on Terraform labs built while preparing for the AWS Certified CloudOps Engineer – Associate exam (formerly SysOps Administrator – Associate). Each folder is a self-contained Terraform project.

## Labs

| Folder | What it builds | Exam topics practised |
|---|---|---|
| [`t3-micro/`](t3-micro/) | A t3.micro EC2 instance in its own VPC, with hibernation, a generated SSH key pair, the CloudWatch agent (procstat for `sshd`) and a `pid_count` alarm with SNS notifications | VPC networking, EC2 hibernation, EBS encryption, IAM instance profiles, CloudWatch agent, procstat, CloudWatch alarms, SNS, drift detection |

## `t3-micro` lab

### Architecture

- **Networking:** dedicated VPC (`10.20.0.0/16`), public subnet (`10.20.1.0/24`), internet gateway, route table
- **Security:** security group allowing SSH only from the deployer's current public IP; IMDSv2 required
- **Compute:** t3.micro running the latest Amazon Linux 2023 (looked up from SSM Parameter Store)
- **Storage:** 8 GiB encrypted gp3 root volume (required for hibernation)
- **Hibernation:** enabled at launch
- **Access:** ED25519 key pair generated by Terraform; private key saved locally with `0400` permissions; SSM Session Manager enabled as a fallback
- **Monitoring:** CloudWatch agent installed via `user_data`, with a `procstat` block watching the `sshd` listener process
- **Alerting:** CloudWatch alarm on `procstat_lookup_pid_count < 1` for 2 minutes (missing data treated as breaching), notifying an SNS topic

### Usage

```bash
cd t3-micro
terraform init
terraform plan
terraform apply                                     # or: terraform apply -var="alert_email=you@example.com"
```

Connect with the `ssh_command` output. Tear everything down with `terraform destroy`.

### Testing the procstat alarm

1. SSH in and confirm the agent is running:
   `sudo /opt/aws/amazon-cloudwatch-agent/bin/amazon-cloudwatch-agent-ctl -a status`
2. Stop the SSH listener (your current session stays open): `sudo systemctl stop sshd`
3. Within ~2–3 minutes the alarm goes to `ALARM`.
4. Restore it: `sudo systemctl start sshd` (or via Session Manager if disconnected).

### Drift detection

```bash
terraform plan -refresh-only                       # report changes made outside Terraform
terraform plan -detailed-exitcode -refresh-only    # exit code 2 = drift found
```

### Notes

- `terraform.tfstate` contains the generated private key in plain text. It is excluded by `.gitignore`; never commit it.
- Running costs: EC2 and EBS while running; EBS only while hibernated or stopped; a few cents a month for custom metrics and the alarm.
